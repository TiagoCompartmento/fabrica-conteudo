Política de Privacidade

Fábrica de Conteúdo (Compartmento) · Última atualização: 18 de novembro de 2026

A Fábrica de Conteúdo é um sistema interno que publica vídeos curtos educativos e infantis somente nos canais do YouTube que pertencem aos próprios responsáveis pelo sistema. Ele não é oferecido a outras pessoas, não tem cadastro de usuários e não acessa canais de terceiros.

Uso dos Serviços de API do YouTube

Este sistema usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Os dados tratados pelo Google seguem a Política de Privacidade do Google.

Quais dados acessamos

Com a autorização do dono do canal (OAuth do Google), o sistema pede apenas duas permissões:

  • youtube.upload: enviar os vídeos produzidos pela fábrica para o canal;
  • youtube.readonly: ler o nome e o identificador do canal, para confirmar que o envio vai para o canal certo.

Não lemos comentários, inscritos, mensagens, histórico de visualização, dados de espectadores nem dados de qualquer outro canal.

O que guardamos

  • O token de acesso da autorização, guardado de forma protegida (arquivo com acesso restrito) no nosso próprio servidor;
  • o identificador e o nome de cada canal autorizado;
  • a lista dos vídeos já enviados (nome do arquivo, data e identificador do vídeo no YouTube), para não enviar o mesmo vídeo duas vezes;
  • a contagem diária de uso da cota da API.

Esses dados ficam somente no nosso servidor. Não usamos cookies nem ferramentas de rastreamento, e não coletamos dados de espectadores.

Compartilhamento

Não vendemos, alugamos nem compartilhamos dados obtidos pelos Serviços de API do YouTube com terceiros. Os dados são usados só para publicar os nossos próprios vídeos.

Guarda e exclusão

O histórico de envios é mantido enquanto o canal estiver em uso pelo sistema. Quando a autorização é revogada ou o canal é removido, o token e os dados daquele canal são apagados do servidor em até 30 dias. Os dados obtidos pela API não são guardados por mais tempo do que permitem as políticas do YouTube.

Como revogar o acesso

O dono do canal pode revogar a qualquer momento o acesso do sistema em security.google.com/settings/security/permissions. A partir da revogação, nenhum envio novo é feito.

Crianças

Os vídeos do canal infantil são marcados como "conteúdo para crianças" no YouTube, como exige a COPPA. O sistema não coleta dados de crianças nem de nenhum espectador.

Privacy Policy

Fábrica de Conteúdo (Compartmento) · Last updated: November 18, 2026

Fábrica de Conteúdo is an internal system that publishes short educational and children's videos only to YouTube channels owned by the people who run the system. It is not offered to other people, has no user sign-up, and never accesses third-party channels.

Use of YouTube API Services

This system uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Data handled by Google is subject to the Google Privacy Policy.

Data we access

With the channel owner's authorization (Google OAuth), the system requests only two scopes:

  • youtube.upload: upload the videos produced by the system to the channel;
  • youtube.readonly: read the channel's title and ID to confirm uploads go to the right channel.

We do not read comments, subscribers, messages, watch history, viewer data, or data from any other channel.

Data we store

  • The OAuth token, stored securely (access-restricted file) on our own server;
  • the ID and title of each authorized channel;
  • a list of uploaded videos (file name, date, YouTube video ID), so the same video is never uploaded twice;
  • a daily count of API quota usage.

This data stays on our server only. We use no cookies or tracking tools and collect no viewer data.

Sharing

We do not sell, rent, or share data obtained through YouTube API Services with any third party. It is used solely to publish our own videos.

Retention and deletion

Upload history is kept while a channel is in use by the system. When authorization is revoked or a channel is removed, its token and data are deleted from our server within 30 days. API data is never stored longer than YouTube's policies allow.

Revoking access

Channel owners can revoke the system's access at any time at security.google.com/settings/security/permissions. After revocation no further uploads are made.

Children

Videos on the children's channel are marked "made for kids" on YouTube, as required by COPPA. The system collects no data from children or any viewer.
